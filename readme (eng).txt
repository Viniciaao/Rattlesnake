Rattlesnake

The mod adds rattlesnakes to the game. You can find them all over the Las Venturas desert, where they blend in wonderfully with the environment. If you get close to a snake, it can bite.

Additionally: Cobra - you can enable it in the .ini file and meet it in Los Santos, but since there is no cobra in North America, it is disabled by default. (restart the game after enabling it)

Script: ArtemQa146
Model, animations, Sounds: Tarzan_3

-----------------------------------------------------------------
Installation:
Move the "Rattlesnake" folder to the "Modloader" folder. Ready!
